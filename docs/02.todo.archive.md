## [已完成] 断流自动续接（DeepSeek 网页 web API `/chat/continue`）

日期：2026-09-11 · 完成：v0.2.8（2026-09-12）

### 背景

DeepSeek 网页生成中途断流（`response/status=INCOMPLETE` + `{"type":"error","finish_reason":"generation_err"}`）时 UI 显示 Continue 按钮，需用户手动点。v0.2.2 先修了 silent 部分（识别信号报 503）；本次把「报错」升级为「自动恢复」。

### 落地内容（与 spec 对齐）

- **parser**（`sse-patch.ts`）：`completionEvents` 第 4 参 `skip: ContinueSkip`；快照裁剪只作用于事件内容、不参与状态判定（`snap.length > 0` 用裁剪前长度，避免简写增量丢帧）；`allowTrim = readySeen && readyId === expectMessageId`（fail-safe，不匹配/无 ready 一律不裁）；带 skip 的流末无终态（空 200/非 SSE）→ 合成 `stream_error('resume ended without terminal status')`
- **adapter**（`client.ts` + `deepseek/adapter.ts`）：`continuePayload` / `continueHeaders`（x-client 指纹、**无 PoW**）；`continueStream` 打 `/chat/continue`（相对路径，无双前缀）；`withPowHeaders` 改为复用 `continueHeaders` + PoW 头
- **router**（`router.ts`）：续接循环放进 `runExclusiveStream` 锁内（单点）——wrapper 拦截事件做 per-message 原始字符计数（message_id 变化清零）+ `stream_stats` 全程累计改写；`RESUMABLE_REASONS={generation_err,incomplete_status}`、上限 3 次、间隔 500ms；`LogEntry.continueAttempts` 进 `FORENSIC_FIELDS`
- spec：`docs/superpowers/specs/2026-09-12-continue-on-incomplete-design.md`；plan：`docs/superpowers/plans/2026-09-12-continue-on-incomplete.md`

### 验证

- 3 个任务 3 次提交（32e5c32 parser / fd2a5f4 adapter / 64e2e8e router），每个任务经独立评审（spec ✅ + quality Approved）
- 468 用例全绿；tsc 0 错；bundle 核验（`continueStream` / `resume ended without terminal status` / `continueAttempts` / `/chat/continue` 均在 extension/sw.js）
- **验收证据**：stub 注入断流 + 真实 parser 消费续接 SSE 的集成用例（16 条用例含中文注释覆盖 spec §4）；真实断流不可按需复现，未做手测
